# About

FastSprout is an open-source Python library for typed backend building blocks.
The project is developed in the
[GitLab repository](https://gitlab.3dcra.eu/opensource/fastsprout/fastsprout)
and mirrored on [GitHub](https://github.com/FastSprout/fastsprout).

FastSprout is licensed under Apache-2.0. Please follow the
[security policy](security.md) to report vulnerabilities privately.
